## 1. Overview

### 1.1 Purpose

블로그 .txt 파일이 생성된 직후, 동일한 내용을 기반으로 카드뉴스 HTML을 자동 생성한다.
사용자는 브라우저에서 HTML을 열고 각 카드를 스크린샷하여 네이버 블로그에 이미지로 첨부한다.

### 1.2 카드뉴스 구성 (7장 고정)

| 카드 번호 | 내용 | 원본 출처 |
|-----------|------|-----------|
| 1장 (표지) | 블로그 제목 + 후킹 한 줄 | .txt 제목 + 도입부 첫 문장 |
| 2장 | 소제목 1 + 핵심 문장 2~3줄 | 첫 번째 ✅ 섹션 |
| 3장 | 소제목 2 + 핵심 문장 2~3줄 | 두 번째 ✅ 섹션 |
| 4장 | 소제목 3 + 핵심 문장 2~3줄 | 세 번째 ✅ 섹션 |
| 5장 | 소제목 4 + 핵심 문장 2~3줄 | 네 번째 ✅ 섹션 |
| 6장 | 소제목 5 + 핵심 문장 2~3줄 | 다섯 번째 ✅ 섹션 |
| 7장 (마무리) | 핵심 요약 bullet 3~4개 + 마무리 문장 | 마무리 섹션 |

### 1.3 Related Documents

- 블로그 글 저장 경로: `C:\Users\SBS\Desktop\글쓰기\output\*.txt`
- 카드뉴스 저장 경로: `C:\Users\SBS\Desktop\글쓰기\output\*_카드뉴스.html`

## 2. Scope

### 2.1 In Scope

- [x] .txt 블로그 파일의 제목·소제목·핵심 문장 자동 추출
- [x] 7장 카드뉴스 HTML 자동 생성 (1:1 비율, 800×800px)
- [x] 한글 웹폰트 적용 (Noto Sans KR - Google Fonts CDN)
- [x] 카드마다 번호 표시 (1/7, 2/7 ...)
- [x] 인쇄/캡처하기 좋은 고정 크기 레이아웃
- [x] 블로그 글(.txt) 생성과 동시에 카드뉴스(.html) 자동 생성

### 2.2 Out of Scope

- 이미지 자동 다운로드 (.png 직접 생성) — 브라우저 캡처로 대체
- 네이버 블로그 자동 업로드
- 배경 사진 삽입 (텍스트+색상 디자인으로 대체)
- 다국어 지원

## 3. Requirements

### 3.1 Functional Requirements

| ID | Requirement | Priority | Status |
|----|-------------|----------|--------|
| FR-01 | .txt 파일에서 제목(📌 제목 칸 아래 텍스트) 자동 추출 | High | Pending |
| FR-02 | .txt 파일에서 ✅ 소제목과 해당 섹션 핵심 문장 2~3줄 추출 | High | Pending |
| FR-03 | .txt 파일의 마무리 섹션 bullet 요약 추출 | High | Pending |
| FR-04 | 7장 HTML 슬라이드 생성 (각 800×800px, 1:1) | High | Pending |
| FR-05 | 카드 상단: 장 번호(N/7), 하단: 브랜드 문구 고정 | Medium | Pending |
| FR-06 | 저장 파일명: `{키워드}_카드뉴스_{YYYYMMDD}.html` | High | Pending |
| FR-07 | 블로그 글 생성 직후 카드뉴스도 함께 생성 (동시 산출) | High | Pending |

### 3.2 Non-Functional Requirements

| Category | Criteria | Measurement Method |
|----------|----------|-------------------|
| 호환성 | Chrome·Edge 브라우저에서 정상 표시 | 직접 열기 확인 |
| 폰트 | 한글 깨짐 없음 (Google Fonts CDN 적용) | 오프라인 불가 시 시스템 폰트 fallback |
| 크기 | 각 카드 800×800px 고정 (캡처 시 정사각형 보장) | 브라우저 개발자 도구 확인 |

## 4. Success Criteria

### 4.1 Definition of Done

- [ ] 키워드 입력 → 블로그 .txt + 카드뉴스 .html 동시 생성
- [ ] 브라우저에서 HTML 열었을 때 7장 모두 정상 표시
- [ ] 각 카드 캡처 후 네이버 블로그에 이미지로 바로 업로드 가능한 품질
- [ ] 한글 폰트 정상 렌더링 (인터넷 연결 시)

### 4.2 Quality Criteria

- [ ] 카드 1장당 텍스트 줄 수: 최대 6줄 (가독성 기준)
- [ ] 배경색·글자색 대비: WCAG AA 수준 이상
- [ ] 카드 번호 표시 정확 (1/7 ~ 7/7)

## 5. Risks and Mitigation

| Risk | Impact | Likelihood | Mitigation |
|------|--------|------------|------------|
| 오프라인 환경에서 Google Fonts 로드 실패 → 폰트 깨짐 | Medium | Low | 시스템 폰트('맑은 고딕', sans-serif) fallback 적용 |
| .txt 파일 구조가 바뀌면 추출 로직 오작동 | Medium | Low | ✅ 마커 기반 파싱 + 구조 변경 시 프롬프트 업데이트 |
| 소제목이 5개 미만이면 빈 카드 생성 | Low | Low | 섹션 수에 따라 카드 수 자동 조정 (최소 3장) |

## 6. 카드뉴스 디자인 스펙

### 6.1 레이아웃 (카드 1장 기준 800×800px)

```
┌──────────────────────────────────┐
│  N / 7                    [우상단]│  ← 장 번호
│                                  │
│                                  │
│   [소제목]                        │  ← 중앙 상단
│                                  │
│   • 핵심 문장 1                   │  ← 본문 (최대 3줄)
│   • 핵심 문장 2                   │
│   • 핵심 문장 3                   │
│                                  │
│──────────────────────────────────│
│  블로그명 또는 키워드    2026     │  ← 하단 고정
└──────────────────────────────────┘
```

### 6.2 색상 테마 (기본)

| 요소 | 색상 |
|------|------|
| 표지(1장) 배경 | #1B4F8A (진한 남색) |
| 표지 글자 | #FFFFFF |
| 본문 카드 배경 | #F8F9FA (연한 회색) |
| 본문 소제목 | #1B4F8A |
| 본문 텍스트 | #333333 |
| 마무리(7장) 배경 | #1B4F8A |
| 마무리 글자 | #FFFFFF |
| 하단 바 | #0D3561 |

## 7. 워크플로우 통합

```
[기존] 키워드 입력
         ↓
     WebSearch + 분석
         ↓
     블로그 글 작성
         ↓
     .txt 저장  ←── 여기까지 기존
         ↓
  [신규] HTML 카드뉴스 생성
         ↓
     .html 저장
         ↓
  [사용자] 브라우저에서 열기
         ↓
  각 카드 스크린샷 (Snipping Tool 등)
         ↓
  네이버 블로그 이미지 첨부
```
