"MBTI 물어보는 사람보다 SBTI 물어보는 사람이 더 많아졌다."

2026년 4월, 중국에서 시작된 성격 검사가 한국을 강타했습니다.
이름은 SBTI.
MBTI의 16가지 유형보다 더 많은 27가지 유형을 제시하며
"이게 나를 더 잘 설명한다"는 반응이 쏟아지고 있습니다.
오늘은 SBTI가 뭔지, MBTI와 뭐가 다른지 한 번에 정리해 드립니다.


■ SBTI란?

정식 명칭은 Silly Big Type Indicator입니다.
2026년 4월 중국 동영상 플랫폼 빌리빌리(Bilibili)의 크리에이터가 만들었습니다.
처음에는 "술을 너무 많이 마시는 친구를 말리기 위해" 만든 장난스러운 검사였습니다.
하지만 업로드 1주일 만에 전 세계로 퍼졌고
2026년 4월 중순부터 한국 SNS와 온라인 커뮤니티에서도 빠르게 확산됐습니다.

학술적 근거가 없는 엔터테인먼트형 성격 검사입니다.
진지한 자기 분석 도구라기보다, 잘 만들어진 인터넷 밈에 가깝습니다.
그래서 재미있습니다.


■ MBTI vs SBTI, 뭐가 다른가?

항목 / MBTI / SBTI
역사 / 약 80년 역사, 카를 융 이론 기반 / 2026년 4월 등장, 학술 근거 없음
목적 / 나는 어떤 사람인가 체계적 이해 / 지금 내 행동이 이 유형이다 공감과 웃음
측정 대상 / 내면의 선천적 성향 / 실제 상황에서의 구체적 행동 패턴
유형 수 / 16가지 / 27가지
분류 기준 / 4개 이분법 축 / 5개 모델, 15개 차원, 삼분법(L/M/H)
결과 표현 / INTJ, ENFP 등 4글자 코드 / CTRL, DRUNK, BOSS 등 기억하기 쉬운 이름
질문 수 / 93개 문항(정식 기준) / 기본 30개 + 추가 1~2개
검사 시간 / 15~20분 / 5~10분
신뢰도 / 학술 검증 완료 / 학술 검증 없음
활용 목적 / 직업 상담, 팀빌딩, 자기 이해 / 자기관찰, SNS 공유, 엔터테인먼트


■ SBTI의 5가지 분류 기준

SBTI는 5개 모델을 기준으로 성격을 분류합니다.

자아 모델 (Self)
나의 한계와 흑역사를 얼마나 타격감 없이 받아들이는가를 측정합니다.
자기 자신에 대한 인식과 수용 방식을 봅니다.

감정 모델 (Emotion)
스트레스 상황에서 분노, 억압, 회피 중 어떤 반응을 보이는가를 측정합니다.

태도 모델 (Attitude)
인생을 대하는 낙관주의와 비관주의의 정도를 봅니다.

행동 모델 (Behavior)
계획을 실제 행동으로 옮기는 동력의 크기를 측정합니다.

사회 모델 (Social)
타인과의 관계에서 에너지를 빼앗기는가, 충전하는가를 봅니다.

각 차원을 L(낮음), M(중간), H(높음) 3단계로 평가해서
패턴 매칭으로 27가지 유형 중 하나를 도출합니다.


■ SBTI 대표 유형들

SBTI 결과는 일반 영어 단어나 줄임말 형식으로 나옵니다.
MBTI의 4글자 코드보다 직관적이고 기억하기 쉽습니다.

CTRL: 통제욕이 강하고 계획적인 유형
BOSS: 리더십이 강하고 자기주장이 뚜렷한 유형
DRUNK: 즉흥적이고 충동적인 행동이 많은 유형
GHOST: 관계에서 조용히 사라지는 회피형 유형
CHAOS: 예측 불가능하고 변화를 즐기는 유형

결과 이름 자체가 SNS에서 공유하기 좋은 밈 형식입니다.
"나 GHOST 나왔어"라는 한 마디로 대화가 이어집니다.


■ 왜 이렇게 빠르게 유행했나?

MBTI 피로도
MBTI가 수년째 유행하면서 "또 MBTI야?"라는 반응이 생겼습니다.
SBTI는 그 자리를 채운 신선한 대안으로 등장했습니다.

높은 공감도
MBTI가 "나는 어떤 성향인가"를 묻는다면
SBTI는 "나는 실제로 어떻게 행동하는가"를 묻습니다.
현대인의 번아웃, 스트레스 대처 방식, 관계 패턴을 더 구체적으로 반영한다는 평가입니다.

SNS 공유 최적화
밈처럼 기억하기 쉬운 결과 이름이 인스타그램, X(트위터), 카카오톡에서 퍼지기 좋습니다.
"내 결과 봐봐" 한 마디로 공유가 완성됩니다.

빠른 검사 시간
5~10분 안에 결과가 나옵니다.
길고 피곤한 질문지 없이 바로 결과를 확인할 수 있습니다.


■ SBTI 무료 검사 방법

공식 SBTI 검사는 아래 방법으로 이용할 수 있습니다.

검색창에 "SBTI 검사" 또는 "SBTI test"를 검색합니다.
sbti.dev 또는 sbti-test.org 같은 영문 사이트에서 영어 기반 검사 이용 가능합니다.
한국어 번역 버전은 커뮤니티에서 공유된 링크를 활용합니다.
소요 시간은 5~10분입니다.


■ SBTI의 한계, 알고 써야 한다

학술적 근거 없음
심리학계의 검증을 거치지 않았습니다.
결과가 시간, 기분, 상황에 따라 달라질 수 있습니다.

라벨링 함정
"나는 GHOST니까 원래 사람을 피한다"는 식으로
결과를 자기 행동의 면죄부로 쓰면 성장이 멈춥니다.

오락용임을 기억할 것
연애 결정이나 진로 선택의 근거로 쓰는 것은 위험합니다.
재미로 보고 공감하는 용도로 활용하는 것이 맞습니다.


■ MBTI와 함께 쓰는 법

SBTI는 MBTI를 대체하는 것이 아닙니다.
서로 다른 것을 측정하기 때문에 함께 보면 더 유용합니다.

MBTI: 나의 선천적 성향과 사고 방식을 이해
SBTI: 현재 내가 실제로 어떻게 행동하고 있는지 점검

MBTI가 "나는 원래 어떤 사람인가"라면
SBTI는 "나는 요즘 어떻게 살고 있는가"에 가깝습니다.
두 개를 함께 보면 선천적 성향과 현재 행동 사이의 간극을 파악할 수 있습니다.


■ 핵심 정리

SBTI 뜻: Silly Big Type Indicator / 2026년 4월 중국발 엔터테인먼트형 성격 검사
MBTI와 차이: MBTI 16가지 vs SBTI 27가지 / 측정 대상과 목적이 다름
분류 기준: 5개 모델(자아·감정·태도·행동·사회) / L·M·H 삼분법
왜 유행: MBTI 피로도 + 높은 공감도 + SNS 공유 용이성
한계: 학술 검증 없음 / 오락용으로만 활용 권장
활용법: MBTI와 함께 보면 더 유용 / 선천적 성향 + 현재 행동 함께 점검

SBTI는 재미있는 도구입니다.
하지만 결과에 나를 맞추지 말고, 결과를 나를 이해하는 출발점으로만 쓰는 것이 좋습니다.
